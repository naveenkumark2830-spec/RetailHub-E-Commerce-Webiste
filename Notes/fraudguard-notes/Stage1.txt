# 9. One important thing to check

Antigravity said:

> `mysql2/promise` connection pool with **in-memory Map fallback repository**

We need to determine whether your test actually persisted into **MySQL**, rather than only the in-memory fallback.

So after the API test, we should query MySQL directly.

If your website uses MySQL locally, run:

```sql
SELECT
    incident_id,
    customer_id,
    fraud_type,
    risk_score,
    risk_level,
    action,
    created_at
FROM fraud_incidents
WHERE incident_id = 'TEST-STAGE1-001';
```

Expected:

```text
TEST-STAGE1-001 | TEST-CUSTOMER-001 | BRUTE_FORCE_LOGIN | 55 | HIGH | STEP_UP_AUTHENTICATION | ...
```

**This is important.** The API returning the incident alone doesn't prove MySQL was used if the fallback Map is active.
